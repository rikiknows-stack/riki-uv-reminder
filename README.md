# ריקי תחדשי לי - PWA עם התראות פוש

## מה יש כאן
- `index.html` - הכלי עצמו (UV חי, טיימר, מד "כמה נשאר", הרשמה להתראות)
- `sw.js` - ה-service worker שמקבל את ההתראות ומציג אותן
- `manifest.json` + `icons/` - מה שהופך את זה לאפליקציה שאפשר להוסיף למסך הבית
- `netlify/functions/subscribe.mjs` - שומר מנויות ב-Netlify Blobs
- `netlify/functions/send-reminders.mjs` - רץ כל שעה, בודק UV לפי מיקום, שולח את המשפטים של ריקי

## פריסה - 4 צעדים

### 1. ליצור מפתחות VAPID (פעם אחת, במחשב)
```
npx web-push generate-vapid-keys
```
מקבלים Public Key ו-Private Key.

### 2. להדביק את המפתח הציבורי בקוד
ב-`index.html`, בשורה הראשונה של הסקריפט:
```
const VAPID_PUBLIC_KEY = 'PASTE_YOUR_VAPID_PUBLIC_KEY_HERE';
```
להחליף בערך של ה-Public Key.

באותו מקום גם לעדכן את `AFFILIATE_URL` לעמוד הקרמים האמיתי.

### 3. משתני סביבה בנטליפיי
Site settings ← Environment variables ← להוסיף:
- `VAPID_PUBLIC_KEY` = המפתח הציבורי
- `VAPID_PRIVATE_KEY` = המפתח הפרטי (לא נכנס לקוד אף פעם!)

### 4. לדחוף לגיטהאב ולחבר לנטליפיי
כמו בכלים הקודמים. נטליפיי יזהה לבד את הפונקציות ואת התזמון השעתי
(`schedule: '0 * * * *'` בתוך send-reminders.mjs).

## בדיקה אחרי פריסה
1. לפתוח את האתר באנדרואיד בכרום ← ללחוץ "הפעילי לי תזכורות" ← לאשר
2. להריץ ידנית: בנטליפיי, Functions ← send-reminders ← אפשר לטרגר דרך
   `https://YOUR-SITE.netlify.app/.netlify/functions/send-reminders`
   (אם ה-UV מעל 3 באזור שלך - תגיע התראה)
3. באייפון: ספארי ← שיתוף ← הוסף למסך הבית ← לפתוח מהאייקון ← להפעיל תזכורות

## הערות
- הודעות נשלחות רק כש-UV מעל 3 ועברו שעתיים מההודעה הקודמת
- הודעת "השמש הלכה הביתה" נשלחת פעם ביום בערב, רק למי שקיבלה תזכורות באותו יום
- מיקומים מעוגלים לרזולוציה של ~10 ק"מ - גם פרטיות וגם פחות קריאות ל-API
- מנויות שבוטלו מנוקות אוטומטית
- מד "כמה נשאר" מופיע אחרי 3 מריחות, ולינק הקרמים מופיע רק כשנשארו 6 מריחות או פחות
